# Чат (Slack)

Проект Hexlet: чат-приложение на React и `@hexlet/chat-server`.

## Требования

- Node.js и npm

## Установка

```bash
make install
```

## Разработка

```bash
make develop
```

Фронтенд: http://localhost:5002  
API сервера: http://localhost:5001

## Сборка и запуск

```bash
make build
make start
```
